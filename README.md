# Módulo de Registro de Donantes - Reto Final Ingeniería de Software

Este repositorio contiene la implementación del módulo de donantes con autenticación JWT, control de acceso por roles, pruebas automatizadas en Jest y pipeline de CI/CD mediante GitHub Actions.

## Instrucciones de ejecución local
1. Instalar dependencias:
   `npm install`
2. Ejecutar la aplicación:
   `npm start`
3. Ejecutar pruebas unitarias con reporte de cobertura:
   `npm test`
